# Registre des décisions

Aucune architecture applicative ni règle métier d'import n'est validée par ce socle.

Pour chaque décision future, créer `NNNN-sujet.md` avec : date, statut (proposée, acceptée ou remplacée), contexte, source de confirmation, décision, conséquences et questions restantes. Une décision remplacée reste lisible et renvoie à la nouvelle.

L'organisation documentaire initiale est un choix de mise en place du 28 octobre 2026, pas une validation des propositions fonctionnelles.
