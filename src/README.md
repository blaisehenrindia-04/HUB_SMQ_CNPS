# Futur code applicatif

Aucun code exécutable à ce stade. Après inventaire, adapter l'arborescence au projet existant.

Responsabilités proposées : lecture des formats confirmés ; mapping et validation ; services partagés exigences/actions ; accès au stockage et contrôles d'autorisation ; composants d'interface des trois sections. Ces responsabilités ne prescrivent ni framework, ni API, ni tables nouvelles.
